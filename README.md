Однооконное приложение случайно перемещает курсор вверх, вниз, влево или вправо и при необходимости возвращает его на прежнее место. Оно предназначено для предотвращения запуска заставки или перехода компьютера в спящий режим, когда системные параметры энергосбережения недоступны.

## Возможности

- настраиваемые интервалы перемещения и возврата в миллисекундах;
- настраиваемое смещение курсора в пикселях;
- включение и отключение перемещения одной кнопкой;
- включение и отключение возврата курсора;
- исключение направлений, которые выводят курсор за границы виртуального экрана;
- отмена возврата, если пользователь сам переместил курсор после автоматического смещения;
- применение нового значения поля через 1 секунду после окончания ввода;
- компактное окно 450 × 140 пикселей с пользовательским центрированным заголовком;
- перетаскивание окна за заголовок, сворачивание и закрытие внутренними кнопками;
- отсутствие файлов настроек и сторонних зависимостей во время работы.

## Запуск из исходного кода

Рекомендуется Python 3.13.x. Во время работы используются только стандартная библиотека Python и системные компоненты.

### Windows и macOS

Установите Python с компонентом Tcl/Tk, затем выполните в каталоге проекта:

```bash
python main.py
```

Также поддерживается запуск модулем:

```bash
python -m mouse_jiggler
```

### Linux

Требуется графический сеанс X11, `tkinter` и системная библиотека `libX11`. Например, для Debian/Ubuntu:

```bash
sudo apt install python3-tk libx11-6
python3 main.py
```

Для Fedora пакет интерфейса называется `python3-tkinter`, для Arch Linux — `tk`.

> В чистом сеансе Wayland глобальное чтение и перемещение курсора намеренно ограничено системой. Запустите приложение в сеансе X11; работа через XWayland зависит от окружения рабочего стола.

## Интерфейс и использование

Окно имеет фиксированный размер и три строки настроек:

1. интервал перемещения и кнопка запуска/остановки;
2. интервал возврата и кнопка включения/отключения возврата;
3. смещение курсора, кнопки «Свернуть» и «Закрыть».

Стандартные системные кнопки в заголовке отсутствуют. Заголовок «Mouse Jiggler» расположен по центру; за него окно можно перетаскивать. Кнопка «Свернуть» сворачивает приложение, а после восстановления окно сохраняет пользовательский заголовок и безрамочный вид.

Порядок работы:

1. Задайте интервал перемещения, интервал возврата и смещение.
2. Нажмите красную кнопку «Mouse Jiggler не действует» для запуска.
3. Зеленая кнопка «Mouse Jiggler действует» останавливает алгоритм.
4. Кнопка «Возвращать курсор» управляет возвратом. При отключении возврата поле его интервала становится неактивным.
5. При необходимости нажмите «Свернуть», чтобы свернуть окно.
6. Для выхода нажмите «Закрыть».

### Правила ввода

- Длина значения во всех полях ограничена **4 символами**, включая знак и десятичный разделитель. Более длинная строка не принимается.
- Максимальное положительное значение, которое можно непосредственно ввести, — `9999`.
- Отрицательное значение преобразуется в положительное, равное ему по модулю.
- Дробная часть отбрасывается.
- Ноль и значения, которые после отбрасывания дробной части меньше `1`, заменяются на `1`.
- Пустое или незавершённое значение восстанавливается до последнего корректного.
- Новое значение применяется через 1 секунду после окончания ввода или при потере полем фокуса.

## Сборка standalone-приложения

Сборка выполняется с помощью PyInstaller. Он нужен **только на компьютере разработчика**: готовому приложению установленный Python и PyInstaller не требуются.

1. Установите Python 3.13.x и Tcl/Tk.
2. В каталоге проекта установите зависимость сборки:

   ```bash
   python -m pip install -r requirements-build.txt
   ```

3. Запустите сборку:

   - Windows: дважды щелкните `build.bat` или выполните `python build.py`;
   - Linux/macOS: выполните `./build.sh` или `python3 build.py`.

Готовые файлы:

| Платформа | Результат |
| --- | --- |
| Windows | `dist/MouseJiggler.exe` |
| Linux | `dist/MouseJiggler` |
| macOS | `dist/MouseJiggler.app` |

Каталоги `build/` и `dist/` можно удалить и создать заново повторной сборкой. PyInstaller не поддерживает кросс-компиляцию: исполняемый файл для каждой ОС нужно собирать на соответствующей ОС. В закрытом контуре заранее поместите пакеты из `requirements-build.txt` и их зависимости в локальный репозиторий или wheelhouse.

## Проверка

Тесты используют только стандартную библиотеку:

```bash
python -m unittest discover -s tests -v
```

Проверяются нормализация и ограничение длины ввода, расположение элементов, центрирование заголовка, сворачивание и восстановление окна, обновление настроек, выбор допустимых направлений, возврат курсора и его отмена после действия пользователя. На Windows дополнительно проверяется чтение реальной позиции курсора и границ виртуального экрана; автоматическое движение мыши тестами не выполняется.
